# Agent entrypoint

This repository is opt-in only: read SKILL.md for its workflow **only after** the user explicitly asks for "Kelip" or "kelip-paper-reading-web"; do not activate on routine PDF/arXiv questions. Same-paper follow-ups may continue an already explicit Kelip session. This is the ChatGPT Web adaptation: local scripts process files; connected tools perform authorized cloud writes. Read references/web-runtime.md and references/archive-workflow.md for routing. Run `python -m unittest discover -s tests -v`, then `python scripts/build_skill.py --out dist` with requirements installed. Never commit user reports, Drive IDs, credentials, vendored build output or test artifacts to this public repository.
